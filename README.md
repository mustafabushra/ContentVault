# إضافة الريلز العربية 🎬

صوتك + السكربت = ريل كامل 4K بدون مونتاج. صنعها مصطفى بن بشرى — [@m.bin_bushra](https://instagram.com/m.bin_bushra)

## التحميل

- **الإضافة:** [arabic-reel-producer.plugin](https://github.com/mustafabushra/contentvault/raw/downloads/arabic-reel-producer.plugin) (أو نسخة [zip](https://github.com/mustafabushra/contentvault/raw/downloads/arabic-reel-producer.zip))
- **الكتيب PDF:** [reel-plugin-guide.pdf](https://github.com/mustafabushra/contentvault/raw/downloads/reel-plugin-guide.pdf)

## التثبيت

1. ثبّت FFmpeg — ماك: `brew install ffmpeg` · ويندوز: `winget install ffmpeg` — وتأكد عندك Python و Node.js.
2. ارفع ملف `arabic-reel-producer.plugin` في محادثة مع Claude على اللابتوب واضغط زر التثبيت.
3. مستخدم Claude Code؟ فك ضغط الملف وشغّل: `claude --plugin-dir ./arabic-reel-producer`

> الإضافة تشتغل على لابتوب أو كمبيوتر. من الجوال تقدر تحمّل الملفات وتسجل صوتك.
